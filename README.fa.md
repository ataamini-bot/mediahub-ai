# MediaHub AI

**فارسی** · [English](README.en.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md)

<div dir="rtl">

ربات تلگرامی قابل نصب روی سرور شخصی برای دانلود رسانه، استخراج صدا، تبدیل فایل و مدیریت اشتراک، با رابط فارسی و انگلیسی.

مدیاهاب ابزارهای رسانه و مدیریت سرویس را داخل تلگرام در اختیار شما می‌گذارد: کاربران لینک می‌فرستند و خروجی را انتخاب می‌کنند؛ مدیران نیز پلن‌ها، پرداخت‌ها، مشتریان و گزارش‌ها را از داخل ربات مدیریت می‌کنند.

این README به فارسی، انگلیسی، روسی و چینی ساده‌شده در دسترس است. رابط خود ربات فعلاً فارسی و انگلیسی است و متن‌های نصاب به انگلیسی نمایش داده می‌شوند.

## وضعیت پروژه

**نامزد انتشار نسخهٔ ۱: `v1.0.0-rc.1`.** کد فعلی در شاخهٔ [`feature/admin-foundation`](https://github.com/ataamini-bot/mediahub-ai/tree/feature/admin-foundation) قرار دارد. این راهنما مربوط به همین نامزد انتشار است؛ شاخهٔ پیش‌فرض مخزن ممکن است نسخهٔ قدیمی‌تری داشته باشد.

دستور نصب زیر از کامیت مشخص `f793c3fe06dafcce0239922577bf7bb64eb756ce` استفاده می‌کند که [آزمون‌های CI](https://github.com/ataamini-bot/mediahub-ai/actions/runs/36895762828) آن موفق بوده‌اند. انتشار پایدار نسخهٔ ۱ همچنان به تکمیل تست‌های زنده و بررسی استقرار وابسته است.

## امکانات

### ابزارهای رسانه

- دانلود از لینک‌های عمومی پشتیبانی‌شده، از جمله YouTube، محتوای عمومی Instagram، TikTok، Facebook، X، Pinterest و Threads.
- انتخاب کیفیت‌های موجود ویدئو تا 4K، مطابق امکانات منبع و تنظیمات پلن.
- استخراج صدا، کاور و توضیحات، در صورت موجودبودن.
- تبدیل رسانهٔ آپلودشده به فرمت‌های صوتی و ویدئویی پشتیبانی‌شده.
- دریافت فایل با نامی برگرفته از عنوان رسانهٔ اصلی.
- دکمه‌های جزئیات، دانلود مجدد و خروجی‌های مرتبط زیر فایل ارسالی.
- نمایش پیشرفت دانلود، سرعت انتقال، حجم فایل و زمان تخمینی باقی‌مانده.

رسانه و فرمت‌های قابل دریافت به سایت منبع بستگی دارند. پشتیبانی Instagram به محتوای عمومی محدود است و از کوکی ورود یا نشست شخصی Instagram استفاده نمی‌کند.

### اشتراک و پرداخت

- پلن‌های رایگان و پولی، مدت اشتراک و محدودیت مصرف قابل تنظیم.
- پرداخت دستی با کارت بانکی و USDT.
- بررسی رسید و شناسهٔ تراکنش در پنل خصوصی مدیر داخل ربات.
- ارسال گزارش پرداخت‌های تأییدشده به تاپیک Payments.
- موجودی اعتبار داخلی مستقل برای تومان و USDT، همراه با سابقهٔ تراکنش و ثبت تراکنش برگشتی.
- کد تخفیف با بازهٔ اعتبار، شرایط استفاده و سقف مصرف.

مدیر سرویس قیمت‌ها، مقصدهای پرداخت، تنظیمات پلن و قواعد تخفیف را از داخل ربات تعیین می‌کند.

### مدیریت

- رابط کاربری فارسی و انگلیسی.
- عضویت اجباری در کانال‌ها بر اساس زبان انتخابی کاربر در ربات.
- جست‌وجوی مشتری، مسدودسازی حساب، مدیریت اشتراک و کنترل سهمیه.
- نقش‌ها و دسترسی‌های مدیران و گزارش فعالیت آن‌ها.
- پیام همگانی با انتخاب مخاطب و زبان، پیش‌نمایش، تأیید، صف پایدار و گزارش ارسال.
- آمار دانلود و پرداخت.
- تاپیک‌های گزارش Monitoring، Payments، Backups، System و Support.
- بکاپ رمزنگاری‌شدهٔ زمان‌بندی‌شده و بررسی صحت بازیابی.

## نصب روی سرور Ubuntu جدید

نصاب برای **Ubuntu Server 22.04، 24.04 یا 26.04 با معماری amd64/x86_64** و دسترسی root یا sudo آماده شده است. ابزارهای لازم میزبان و اجزای Docker را نصب می‌کند و سپس سرویس‌های برنامه را با Docker Compose اجرا می‌کند.

پیش از شروع این اطلاعات را آماده کنید:

| ورودی | محل دریافت |
| --- | --- |
| Bot Token | ربات خود را در [@BotFather](https://t.me/BotFather) بسازید |
| Telegram API ID و API Hash | برنامهٔ خود را در [my.telegram.org/apps](https://my.telegram.org/apps) ثبت کنید |
| Superadmin Telegram ID | شناسهٔ عددی حساب تلگرامی که مدیر اصلی ربات خواهد بود |
| منطقهٔ زمانی | پیش‌فرض: `Asia/Tehran` |

**Bot Token مشخص می‌کند کدام ربات روی سرور اجرا شود.** شناسهٔ سوپرادمین، شناسهٔ عددی کاربر تلگرام است؛ شمارهٔ موبایل، شناسهٔ ربات یا API ID نیست. سرویس Local Bot API به API ID و API Hash نیاز دارد.

روی سرور تازه‌ای که مسیر `/opt/mediahub-ai` از قبل در آن وجود ندارد، اجرا کنید:

<div dir="ltr">

```bash
(
  set -euo pipefail
  release='f793c3fe06dafcce0239922577bf7bb64eb756ce'
  sudo apt-get update
  sudo apt-get install -y ca-certificates curl
  installer="$(mktemp /tmp/mediahub-install.XXXXXX)"
  trap 'rm -f "$installer"' EXIT
  curl --proto '=https' -fsSL \
    "https://raw.githubusercontent.com/ataamini-bot/mediahub-ai/${release}/install.sh" \
    -o "$installer"
  sudo bash "$installer" "$release" install
)
```

</div>

این دستور نصب را مستقیماً شروع می‌کند. نامزد بدون تگ، ایمیج‌های برنامه را روی خود سرور می‌سازد. پرسش‌های نصاب را پاسخ دهید؛ پیش از ورود به مرحلهٔ تنظیم گروه تلگرام باید پیام `INSTALLATION=OK` را ببینید.

نصاب رمز دیتابیس و کلیدهای برنامه را تولید می‌کند. یک کپی امن از فایل `/opt/mediahub-ai/.mediahub/recovery-key.txt` خارج از سرور و جدا از بکاپ‌ها نگه دارید؛ برای رمزگشایی بکاپ هنگام بازیابی به این کلید نیاز دارید.

پس از نصب، با حساب سوپرادمین وارد ربات شوید، **Start** را بزنید و پنل مدیریت را باز کنید.

## تنظیم گروه گزارش‌ها

1. یک گروه خصوصی در تلگرام، مثلاً با نام **MediaHub Reports**، بسازید.
2. گزینهٔ **Topics / موضوعات** را در تنظیمات گروه فعال کنید.
3. دقیقاً همان رباتی را اضافه کنید که توکنش را هنگام نصب وارد کرده‌اید.
4. ربات را با دسترسی **Manage Topics / مدیریت موضوعات** ادمین کنید.
5. هنگام پرسش `Supergroup ID`، شناسهٔ عددی گروه را وارد کنید.
6. نام گروه نمایش‌داده‌شده را بررسی و ساخت تاپیک‌های گزارش را تأیید کنید.

برای مثال، لینک پیام خصوصی `https://t.me/c/1234567890/5` به گروهی با شناسهٔ **`-1001234567890`** مربوط است. عدد آخر، یعنی `5`، شناسهٔ پیام است. از شناسهٔ گروه خودتان استفاده کنید.

نصاب تاپیک‌های **Monitoring**، **Payments**، **Backups**، **System** و **Support** را می‌سازد و شناسه‌هایشان را ذخیره می‌کند. سپس می‌توانید کانال‌های عضویت اجباری را برای مخاطبان `fa`، `en` یا `all` اضافه کنید؛ ربات باید در آن کانال‌ها هم ادمین باشد.

برای ادامهٔ تنظیم گروه در زمانی دیگر:

<div dir="ltr">

```bash
sudo mediahub telegram
```

</div>

## مدیریت سرور

منوی مدیریت سرور را باز کنید:

<div dir="ltr">

```bash
sudo mediahub
```

</div>

متن منو و پرسش‌های ترمینال انگلیسی است. رابط خود ربات فارسی و انگلیسی دارد.

| گزینه | کارکرد |
| --- | --- |
| 1 | نصب MediaHub |
| 2 | به‌روزرسانی به نسخهٔ پایدار |
| 3 | ساخت و خروجی بکاپ |
| 4 | ورود بکاپ و بازیابی |
| 5 | گروه، تاپیک‌ها و کانال‌های عضویت اجباری |
| 6 | بررسی سلامت سیستم |
| 7 | بازگشت نسخهٔ برنامه |
| 8 | تنظیم منبع به‌روزرسانی |
| 9 | حذف کانتینرها با حفظ داده‌ها |
| 0 | خروج |

برای دریافت گزارش سلامت از خط فرمان:

<div dir="ltr">

```bash
cd /opt/mediahub-ai
sudo bash scripts/check_launch.sh
```

</div>

پیام `SERVER_CHECK=OK` موفقیت بررسی‌های خودکار سرور را نشان می‌دهد. عملکرد زندهٔ ربات را جداگانه آزمایش کنید: ربات را Start کنید، یک فایل کوچک دریافت کنید و پنل مدیریت و تاپیک‌های گزارش را بررسی کنید.

## بکاپ، بازیابی و به‌روزرسانی

بکاپ‌ها شامل داده‌های PostgreSQL، تنظیمات محیط برنامه و فایل‌های پوشهٔ `secrets` هستند. فایل‌های رسانهٔ دانلودشده، صف‌های Redis و ایمیج‌های Docker در آن‌ها قرار نمی‌گیرند. آرشیوها رمزنگاری می‌شوند و صحت آن‌ها با بازیابی آزمایشی در محیط جدا بررسی می‌شود.

برای ساخت بکاپ قابل انتقال از **Create and export backup** و برای بازیابی از **Import backup and restore** استفاده کنید. فایل آرشیو `.mhb`، فایل مشخصات `.json` مربوط به آن و کلید بازیابی را نگه دارید. پیش از انتقال همان ربات به سرور جدید، نصب قبلی را متوقف کنید.

به‌روزرسانی پایدار به تگ منتشرشده و ایمیج‌های همان نسخه نیاز دارد. در تنظیم منبع به‌روزرسانی می‌توان مخزن Git با HTTPS و رجیستری کانتینر را مشخص کرد. پیش از تغییر ساختار دیتابیس، بکاپ بررسی‌شده تهیه می‌شود و ایمیج‌های قبلی برنامه برای بازگشت سازگار نگه داشته می‌شوند. بازگشت نسخهٔ برنامه، دیتابیس را خودکار به ساختار قبلی برنمی‌گرداند.

مراحل کامل و تفاوت بازیابی روی نصب موجود با بازیابی روی سرور تازه در [راهنمای نصب و بازیابی](https://github.com/ataamini-bot/mediahub-ai/blob/feature/admin-foundation/docs/INSTALLATION.md) آمده است.

## پاک‌سازی رسانه و داده‌های نگهداری‌شده

فایل‌های دانلودشده و خروجی‌های تولیدشده، فایل کاری موقت هستند و پس از ارسال حذف می‌شوند. پاک‌سازی پس‌زمینه، فایل‌های واجد شرایطِ باقی‌مانده از درخواست‌های قطع‌شده یا ناموفق را بررسی می‌کند؛ بعضی مسیرهای بازیابی و پاک‌سازی کش مهلت نگهداری دارند.

لینک‌های منبع و مشخصات دانلود برای گزارش فعالیت مدیر، سهمیه‌ها و مدیریت سرویس در دیتابیس باقی می‌مانند. سوابق پرداخت، اشتراک و اعتبار داخلی هم نگهداری می‌شوند. کاربر منوی تاریخچهٔ دانلود ندارد و لینک کامل منبع در جزئیات فایل ارسالی نشان داده نمی‌شود. بکاپ دیتابیس شامل سوابق نگهداری‌شده است.

حذف فایل از سرور، نسخه‌ای را که قبلاً در تلگرام ارسال شده حذف نمی‌کند. جزئیات رفتار در [راهنمای پاک‌سازی فایل رسانه](https://github.com/ataamini-bot/mediahub-ai/blob/feature/admin-foundation/docs/MEDIA_FILE_CLEANUP.md) آمده است.

## معماری

| سرویس | مسئولیت |
| --- | --- |
| Bot | رابط تلگرام، مراحل کاربر و پنل مدیر با aiogram |
| Backend | برنامهٔ FastAPI، قواعد سرویس و دسترسی به دیتابیس |
| Worker | اجرای کارهای دانلود و پردازش رسانه با Celery |
| Monitor | نظارت بر سرویس‌ها و گزارش‌های عملیاتی |
| Backup | بکاپ رمزنگاری‌شدهٔ زمان‌بندی‌شده و بررسی بازیابی |
| PostgreSQL | داده‌های پایدار برنامه |
| Redis | صف کارها و وضعیت موقت |
| Local Bot API | سرویس API تلگرام برای انتقال محلی رسانه |

پردازش رسانه با yt-dlp و FFmpeg انجام می‌شود. Alembic تغییرات ساختار دیتابیس را مدیریت می‌کند و Docker Compose استقرار سرویس‌ها را تعریف می‌کند.

## رفع مشکلات رایج

| پیام یا نشانه | موردی که باید بررسی شود |
| --- | --- |
| `Telegram getChat: Bad Request: chat not found` | شناسهٔ گروه و عضویت همان ربات نصب‌شده در همان گروه را بررسی کنید؛ سپس `sudo mediahub telegram` را دوباره اجرا کنید. |
| خطای Topics یا دسترسی مدیر | Topics گروه را فعال کنید و دسترسی Manage Topics را به ربات بدهید. |
| `Another installation or recovery operation is running` | یک منو یا عملیات قبلی قفل را نگه داشته است. منوی قبلیِ منتظر انتخاب را با `0` ببندید یا منتظر پایان عملیات فعال بمانید. |
| ربات در فهرست گفت‌وگوها دیده نمی‌شود | نام کاربری ربات مربوط به Bot Token را باز کنید و Start بزنید. |
| ربات پس از Start پاسخ نمی‌دهد | بررسی سلامت را اجرا کنید و مطمئن شوید توکن ربات هم‌زمان در نصب فعال دیگری استفاده نمی‌شود. |
| `Destination exists` | از ابزارهای مدیریت نصب موجود استفاده کنید؛ نصاب اولیه پوشهٔ موجود را بازنویسی نمی‌کند. |
