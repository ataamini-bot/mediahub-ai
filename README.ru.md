# MediaHub AI

[فارسی](README.fa.md) · [English](README.en.md) · **Русский** · [简体中文](README.zh-CN.md)

Telegram-бот для размещения на собственном сервере: загрузка медиа, извлечение аудио, конвертация файлов и управление подписками. Интерфейс бота доступен на персидском и английском языках.

MediaHub объединяет инструменты для работы с медиа и администрирование в Telegram. Пользователи отправляют ссылки и выбирают результат, а администраторы управляют тарифами, платежами, клиентами и отчётами прямо в боте.

Этот README доступен на персидском, английском, русском и упрощённом китайском языках. Сам бот пока поддерживает персидский и английский, а установщик задаёт вопросы на английском.

## Статус проекта

**Кандидат в релиз версии 1: `v1.0.0-rc.1`.** Текущая реализация находится в ветке [`feature/admin-foundation`](https://github.com/ataamini-bot/mediahub-ai/tree/feature/admin-foundation). Этот README описывает именно её; ветка репозитория по умолчанию может содержать более раннюю версию.

Команда установки ниже использует фиксированный коммит `f793c3fe06dafcce0239922577bf7bb64eb756ce`, успешно прошедший [CI](https://github.com/ataamini-bot/mediahub-ai/actions/runs/36895762828). Выпуск стабильной версии 1 зависит от завершения приёмочных испытаний в реальных условиях и проверки развёртывания.

## Возможности

### Работа с медиа

- Загрузка по поддерживаемым публичным ссылкам, включая YouTube, общедоступный контент Instagram, TikTok, Facebook, X, Pinterest и Threads.
- Выбор доступного качества видео вплоть до 4K с учётом источника и настроек тарифа.
- Извлечение аудио, обложек и описаний, если они доступны.
- Конвертация загруженных файлов в поддерживаемые видео- и аудиоформаты.
- Имена отправляемых файлов на основе названия исходного медиа.
- Кнопки просмотра сведений, повторной загрузки и получения других результатов под отправленным файлом.
- Отображение прогресса загрузки, скорости передачи, размера файла и примерного оставшегося времени.

Доступные медиа и форматы зависят от сайта-источника. Для Instagram поддерживается только общедоступный контент; cookies для входа и личные сессии Instagram не используются.

### Подписки и платежи

- Настраиваемые бесплатные и платные тарифы, сроки подписки и лимиты использования.
- Оплата банковской картой и USDT с ручным подтверждением.
- Проверка квитанций и идентификаторов транзакций в приватной панели администратора бота.
- Отчёты о подтверждённых платежах в теме Payments.
- Отдельные внутренние балансы в томанах и USDT с историей операций и обратными проводками.
- Промокоды со сроками действия, условиями применения и ограничениями использования.

Оператор сервиса задаёт цены, платёжные реквизиты, параметры тарифов и правила скидок через бота.

### Администрирование

- Пользовательский интерфейс на персидском и английском языках.
- Обязательная подписка на каналы с учётом выбранного пользователем языка бота.
- Поиск клиентов, блокировка аккаунтов, управление подписками и квотами.
- Роли и права администраторов, журнал их действий.
- Массовые рассылки с выбором аудитории и языка, предпросмотром, подтверждением, сохраняемой очередью и отчётами о доставке.
- Статистика загрузок и платежей.
- Темы для отчётов: Monitoring, Payments, Backups, System и Support.
- Зашифрованные резервные копии по расписанию и проверка восстановления.

## Установка на новый сервер Ubuntu

Установщик рассчитан на **Ubuntu Server 22.04, 24.04 или 26.04 с архитектурой amd64/x86_64** и доступом root или sudo. Он устанавливает необходимые системные инструменты и компоненты Docker, затем запускает сервисы приложения через Docker Compose.

Перед началом подготовьте следующие данные:

| Значение | Где получить |
| --- | --- |
| Bot Token | Создайте своего бота через [@BotFather](https://t.me/BotFather) |
| Telegram API ID и API Hash | Зарегистрируйте приложение на [my.telegram.org/apps](https://my.telegram.org/apps) |
| Superadmin Telegram ID | Числовой ID аккаунта, который будет главным администратором бота |
| Часовой пояс | По умолчанию: `Asia/Tehran` |

**Bot Token определяет, какой бот будет работать в этой установке.** ID суперадминистратора — это числовой ID пользователя Telegram, а не номер телефона, ID бота или API ID. Сервису Local Bot API необходимы API ID и API Hash.

Выполните команду на новом сервере, где каталог `/opt/mediahub-ai` ещё не существует:

```bash
(
  set -euo pipefail
  release='f793c3fe06dafcce0239922577bf7bb64eb756ce'
  sudo apt-get update
  sudo apt-get install -y ca-certificates curl
  installer="$(mktemp /tmp/mediahub-install.XXXXXX)"
  trap 'rm -f "$installer"' EXIT
  curl --proto '=https' -fsSL \
    "https://raw.githubusercontent.com/ataamini-bot/mediahub-ai/${release}/install.sh" \
    -o "$installer"
  sudo bash "$installer" "$release" install
)
```

Команда сразу запускает установку. Для кандидата без тега образы приложения собираются на самом сервере. Следуйте подсказкам: перед переходом к настройке группы Telegram должно появиться сообщение `INSTALLATION=OK`.

Установщик создаёт пароль базы данных и секреты приложения. Сохраните защищённую копию файла `/opt/mediahub-ai/.mediahub/recovery-key.txt` вне сервера и отдельно от резервных копий: этот ключ нужен для расшифровки архива при восстановлении.

После установки откройте бота в Telegram с аккаунта суперадминистратора, нажмите **Start** и перейдите в панель администратора.

## Настройка группы для отчётов

1. Создайте приватную группу Telegram, например **MediaHub Reports**.
2. Включите **Topics / Темы** в настройках группы.
3. Добавьте именно того бота, токен которого вы указали при установке.
4. Назначьте бота администратором с правом **Manage Topics / Управление темами**.
5. Когда установщик запросит `Supergroup ID`, введите числовой ID группы.
6. Проверьте показанное название группы и подтвердите создание тем для отчётов.

Например, ссылка на сообщение в приватной группе `https://t.me/c/1234567890/5` соответствует ID группы **`-1001234567890`**. Последняя цифра `5` — ID сообщения. Используйте идентификатор своей группы.

Установщик создаёт темы **Monitoring**, **Payments**, **Backups**, **System** и **Support** и сохраняет их ID. Затем можно добавить каналы для обязательной подписки, выбрав аудиторию `fa`, `en` или `all`. В этих каналах бот тоже должен быть администратором.

Чтобы продолжить настройку группы позже:

```bash
sudo mediahub telegram
```

## Управление сервером

Откройте меню управления сервером:

```bash
sudo mediahub
```

Меню и подсказки в терминале отображаются на английском. Сам бот поддерживает персидский и английский языки.

| Пункт | Действие |
| --- | --- |
| 1 | Установить MediaHub |
| 2 | Обновить до стабильного релиза |
| 3 | Создать и экспортировать резервную копию |
| 4 | Импортировать резервную копию и выполнить восстановление |
| 5 | Настроить группу, темы и каналы для обязательной подписки |
| 6 | Проверить состояние системы |
| 7 | Откатить версию приложения |
| 8 | Настроить источник обновлений |
| 9 | Удалить контейнеры с сохранением данных |
| 0 | Выйти |

Для получения отчёта о состоянии из командной строки:

```bash
cd /opt/mediahub-ai
sudo bash scripts/check_launch.sh
```

Сообщение `SERVER_CHECK=OK` означает, что автоматические проверки сервера прошли успешно. Работу бота в реальных условиях проверяйте отдельно: нажмите Start, загрузите небольшой файл, проверьте панель администратора и темы для отчётов.

## Резервные копии, восстановление и обновления

Резервные копии содержат данные PostgreSQL, настройки окружения приложения и файлы из каталога `secrets`. Загруженные медиафайлы, очереди Redis и образы Docker в них не входят. Архивы шифруются и проверяются пробным восстановлением в изолированной среде.

Для создания переносимой резервной копии выберите **Create and export backup**, а для восстановления — **Import backup and restore**. Сохраните архив `.mhb`, соответствующий ему файл описания `.json` и ключ восстановления. Перед переносом того же бота на новый сервер остановите старую установку.

Стабильное обновление требует опубликованного тега релиза и соответствующих образов контейнеров. В настройках источника обновлений можно указать Git-репозиторий с HTTPS и реестр контейнеров. Перед миграцией базы данных создаётся проверенная резервная копия, а предыдущие образы приложения сохраняются для совместимого отката. Откат приложения не возвращает автоматически прежнюю схему базы данных.

Полные процедуры и различия между восстановлением существующей установки и переносом на новый сервер описаны в [руководстве по установке и восстановлению на персидском языке](https://github.com/ataamini-bot/mediahub-ai/blob/feature/admin-foundation/docs/INSTALLATION.md).

## Очистка медиа и сохраняемые данные

Загруженные и созданные медиафайлы являются временными рабочими файлами и удаляются после отправки. Фоновая очистка обрабатывает подходящие под её условия файлы, оставшиеся после прерванных или неудачных заданий. Для некоторых сценариев восстановления и очистки кеша предусмотрены сроки хранения.

Ссылки на источники и метаданные загрузок сохраняются в базе для журнала активности, учёта квот и администрирования. Также сохраняются записи о платежах, подписках и внутреннем балансе. Пользователям не предоставляется меню истории загрузок, а полные ссылки на источники не показываются в сведениях об отправленных файлах. Резервные копии базы содержат сохранённые записи.

Удаление файла с сервера не удаляет копию, уже отправленную в Telegram. Точное поведение описано в [документации по очистке медиафайлов на персидском языке](https://github.com/ataamini-bot/mediahub-ai/blob/feature/admin-foundation/docs/MEDIA_FILE_CLEANUP.md).

## Архитектура

| Сервис | Назначение |
| --- | --- |
| Bot | Интерфейс Telegram, пользовательские сценарии и панель администратора на aiogram |
| Backend | Приложение FastAPI, бизнес-логика и доступ к базе данных |
| Worker | Задания Celery для загрузки и обработки медиа |
| Monitor | Мониторинг сервисов и эксплуатационные отчёты |
| Backup | Зашифрованные резервные копии по расписанию и проверка восстановления |
| PostgreSQL | Постоянные данные приложения |
| Redis | Очередь заданий и временное состояние |
| Local Bot API | API-сервис Telegram для локальной передачи медиа |

Для обработки медиа используются yt-dlp и FFmpeg. Миграциями базы данных управляет Alembic. Конфигурация развёртывания задаётся в Docker Compose.

## Решение распространённых проблем

| Сообщение или симптом | Что проверить |
| --- | --- |
| `Telegram getChat: Bad Request: chat not found` | Проверьте ID группы и участие именно установленного бота в этой группе. Затем повторите `sudo mediahub telegram`. |
| Ошибка Topics или прав администратора | Включите темы в группе и предоставьте боту право Manage Topics. |
| `Another installation or recovery operation is running` | Предыдущее меню или операция удерживает блокировку. Закройте ожидающее выбора меню пунктом `0` или дождитесь завершения активной операции. |
| Бот не появился в списке чатов | Откройте имя пользователя бота, соответствующего указанному Bot Token, и нажмите Start. |
| Нет ответа после Start | Запустите проверку состояния и убедитесь, что токен бота не используется другой активной установкой. |
| `Destination exists` | Используйте инструменты управления существующей установкой: начальный установщик не перезаписывает каталог. |
