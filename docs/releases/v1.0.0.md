# MediaHub AI 1.0.0

MediaHub is a self-hosted Telegram bot for downloading public media, extracting audio and managing subscriptions. Users and admins can work in Persian or English. Installation guides are available in Persian, English, Russian and Simplified Chinese.

- **Media:** choose an available quality and playback device; receive a file named after the media and request another output directly beneath it. Media files are temporary. Source links stay in the database for authorized admins; users do not have a download-history menu.
- **Payments:** review receipts privately in the bot and send approved-payment reports to the Payments topic. Plans, separate Toman and USDT credit balances, and discount codes are managed from the admin panel.
- **Administration:** configure required channels by language, support tickets, broadcasts and reports. Authorized admins can enter a Telegram ID to receive a private Excel report of that user's download links, ordered by Tehran time.
- **Operations:** the Ubuntu/Docker console installs and updates the stack, configures reporting topics, exports encrypted backups, restores them and can roll back compatible application images. Database rollback uses the separate recovery procedure.

For installation, choose a language in the [project README](https://github.com/ataamini-bot/mediahub-ai#readme). On an existing managed installation run `sudo mediahub update v1.0.0`; it verifies a backup before applying migrations. Keep a separate off-server copy of the recovery key.
